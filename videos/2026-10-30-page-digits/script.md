# How Many Pages Does the Book Have? | AMC 8-Style Level 4

## Intro

Number the pages of a book, and count every digit you print.

Here's a surprise. Ninety-nine pages use one hundred eighty-nine digits, not twice ninety-nine.

Hi there, I'm Vantee! Let's find out why, and crack today's puzzle.

## The question

Here's the question.

The pages of a book are numbered in order, starting at page one.

The total number of digits printed is exactly twice the number of pages.

How many pages does the book have? Here are the five choices.

## What are we asked?

Let's break it down. Page seven uses one digit.

Page forty-two uses two digits. Page one hundred five uses three digits.

Take a small book with twelve pages. Nine pages with one digit, then three pages with two.

That's fifteen digits. Twice twelve is twenty-four, so fifteen digits is too few.

We want a book where the digits equal two times the pages, exactly.

## Solution 1: count in groups

Welcome back! Let's count the digits in groups.

Pages one to nine are nine pages with one digit each. That's nine digits.

Pages ten to ninety-nine are ninety pages with two digits each: one hundred eighty digits.

So a book of ninety-nine pages uses one hundred eighty-nine digits.

But our target, twice the pages, is one hundred ninety-eight. We're nine digits short.

Each two-digit page adds two digits, and our target grows by two. The gap never closes.

So no book under one hundred pages works. We need some three-digit pages.

Page one hundred adds three digits, but the target only grows by two.

So the gap shrinks from nine digits to eight digits.

Every three-digit page closes the gap by one more digit.

After nine three-digit pages, the gap is zero! That's page one hundred eight.

Let's check. Nine, plus one hundred eighty, plus twenty-seven, is two hundred sixteen digits.

And twice one hundred eight is two hundred sixteen. It matches! That's Choice C.

## Solution 2: the balance trick

Here's a faster way. Pretend every page owes exactly two digits.

A one-digit page pays only one. So each one is one digit short.

Nine one-digit pages leave us nine digits short.

A two-digit page pays exactly two. Those pages are perfectly even.

A three-digit page pays three, so each one gives one extra digit.

To cancel nine missing digits, we need nine three-digit pages: page one hundred to one hundred eight.

After that, every new page adds an extra digit, so we can never balance again.

So one hundred eight pages is the only answer!

So when would you pick each way? Counting in groups gives you the totals to check.

The balance trick is faster, because it skips all the big sums.

## Common traps

Choice A, ninety-nine pages, forgets that pages one to nine have one digit. It's nine digits short.

Choice B, one hundred pages, is a nice round guess. It's still eight digits short.

Choice D, one hundred seventeen pages, goes too far. It uses two hundred forty-three digits.

But twice the pages is only two hundred thirty-four. That's nine digits too many.

Choice E is one hundred eighty-nine. That counts digits, not pages!

So here's a great habit: count the digits for your answer, and check it.

## Three times: the answer

Let's use the balance trick again. This time, each page owes three digits.

Each one-digit page is two digits short. Nine pages make eighteen digits short.

Each two-digit page is one digit short. Ninety pages make ninety digits short.

Add them up. Eighteen plus ninety gives one hundred eight missing digits.

Three-digit pages are even. Each four-digit page gives one extra digit.

So we need one hundred eight four-digit pages: from one thousand to one thousand one hundred seven!

If you found one thousand one hundred seven pages, amazing work!

## Recap

Here's the big idea to remember.

Count the digits in groups: one-digit pages, then two-digit pages, then three-digit pages.

Then track the gap to the target, and find where it hits zero.
